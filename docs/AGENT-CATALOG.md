# فهرس مجالات الوكلاء

تحتوي الحزمة على 621 ملف وكيل نشط في `.opencode/agents/`، مع منسق عام باسم `orchestrator`. تتوزع الملفات على المجلدات التالية:

| المجال | مسار الملفات | أمثلة نطاقات |
|---|---|---|
| أنظمة الوكلاء | `agent-systems/` | تنسيق الأدوات والوكلاء وسير العمل |
| الذكاء الاصطناعي والتعلم الآلي | `ai-ml/` | نماذج ML وLLM وهندسة المطالبات |
| المعمارية | `architecture/` | تصميم الأنظمة والقرارات المعمارية |
| Backend | `backend/` | الخدمات وواجهات API والتكاملات الخلفية |
| البيانات | `data/` | هندسة البيانات والتحليلات والتخزين |
| التوثيق | `documentation/` | كتابة الوثائق وإدارة المعرفة |
| Frontend | `frontend/` | واجهات الويب وتجربة المستخدم |
| اللغات | `languages/` | خبراء لغات وأطر برمجية متعددة |
| الأداء | `performance/` | التحليل والتحسين والتحميل |
| المنصة والتشغيل | `platform/` | DevOps والبنية التحتية والنشر |
| المنتج | `product/` | إدارة المنتج والبحث والتخطيط |
| الجودة | `quality/` | الاختبارات ومراجعة الجودة |
| الأمن | `security/` | النمذجة والاختبارات والحوكمة الأمنية |
| مجالات متخصصة | `specialized-domains/` | مجالات تقنية ومهنية متنوعة |

هذه أسماء مجلدات وليست قائمة كاملة بالأدوار. للحصول على المعرف الدقيق لكل وكيل راجع [`AGENT-MANIFEST.csv`](../AGENT-MANIFEST.csv)، وللاستخدام راجع [دليل الوكلاء](USING-AGENTS.md). يمكن أن ينمو عدد الملفات أو تتغير الأمثلة مع تحديثات المستودع.

## قراءة manifest

يحتوي البيان على معرف الوكيل ومسار المصدر وحجمه وبصمة SHA-256 وغيرها من الحقول التي يستخدمها المثبت لمطابقة الملفات. لا تعدل البيان يدوياً لتجاوز تحقق؛ يجب أن تعكس قيمه الملفات الفعلية وأن تبقى مطابقة لمولد البيان المعتمد.

## الوكلاء المعطلون والملفات غير المكتملة

ملفات الوكلاء النشطة موجودة في `.opencode/agents/`. قد يتضمن المستودع fixture للتقييم معطلاً أو عينات غير مكتملة في `quarantine/`؛ هذه ليست جزءاً من الوكلاء القابلة للاكتشاف ولا يثبتها المثبت.
