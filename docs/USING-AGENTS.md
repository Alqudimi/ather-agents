# استخدام الوكلاء

## اختيار نقطة البداية

- اختر `orchestrator` عندما تكون المهمة متعددة التخصصات أو تحتاج تنسيقاً بين فرق. يحدد المنسق الفرق ذات الصلة ويجمع النتائج؛ لا يفترض أن يستدعي كل الوكلاء.
- اختر قائد فريق عندما تكون المهمة ضمن مجال واحد وتريد نتيجة مباشرة من ذلك المجال.
- اختر اختصاصياً فرعياً عندما تعرف نوع العمل المطلوب بدقة.

أسماء ومعرفات الوكلاء موجودة في [`AGENT-MANIFEST.csv`](../AGENT-MANIFEST.csv)، والتقسيم في `.opencode/agents/`. يظهر المسار المتداخل ضمن معرف الوكيل.

## صياغة طلب فعّال

أعط الوكيل نتيجة واضحة بدلاً من تكليف فضفاض. اذكر:

1. الهدف والمخرج الذي تريده.
2. سياق المشروع والتقنيات أو الملفات ذات الصلة.
3. القيود (الوقت، التوافق، الميزانية، الأسلوب، أو نطاق التعديل).
4. ما لا يجب تغييره أو إرساله.
5. طريقة التحقق المطلوبة، مثل الاختبارات أو مراجعة الفروقات.

مثال:

> راجع مسار تسجيل الدخول في هذا المشروع، وحدد الثغرات القابلة للاستغلال مع الإشارة إلى الملفات والأسطر. لا تعدّل أي ملف. أعطني النتائج مرتبة حسب الخطورة، ثم قائمة اختبارات مقترحة.

مثال للتنسيق:

> أضف نقطة API لاسترجاع سجل المستخدم. نسّق مع قائد backend عند الحاجة، حافظ على واجهات المشروع الحالية، أضف اختبارات، ولا تغيّر إعدادات النشر. اعرض الملفات التي ستعدلها ونتائج الاختبارات.

## فهم التفويض

تستخدم الحزمة تسلسل `orchestrator → team lead → specialist` عند تفعيل `experimental.subagent_depth: 2`. جلسات الوكلاء الفرعية تبدأ بسياقها الخاص، وقد تحتاج إلى تمرير المعلومات الأساسية بوضوح في المهمة. الأذونات الفعلية تعتمد على إعدادات OpenCode وعلى قواعد كل وكيل؛ وجود الوكيل لا يمنحه تلقائياً صلاحيات نظام أو مفاتيح أو ذاكرة مشتركة.

## تحقق من النتائج

تعامل مع المخرجات كمساعدة لا كضمان. راجع تغييرات الملفات يدوياً، شغّل الاختبارات، وافحص الأوامر والاعتمادات المقترحة قبل تنفيذها، خصوصاً ما يتعلق بالحذف أو الإنتاج أو البيانات الحساسة أو الأمان. لا تدخل أسراراً في prompt إلا إذا كانت آلية العمل مصممة ومصرحاً بها لذلك.

## إذا لم يظهر الوكيل

شغّل `opencode debug agents` من جذر المشروع. إذا لم يظهر، اتبع [دليل التثبيت](INSTALLATION.md) و[استكشاف الأخطاء](TROUBLESHOOTING.md)، وتأكد أن مسار الملف تحت `.opencode/agents/` وأن frontmatter صالح لـV2.
