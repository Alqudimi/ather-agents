# الأسئلة الشائعة

## هل يثبت هذا المشروع OpenCode؟

لا. يجب تثبيت OpenCode v2 بنفسك أولاً. أوامر التثبيت والتحقق تتوقف برسالة واضحة إذا لم تجد v2، ولا تحاول تنزيله أو استبداله. ويمكن إزالة ملفات الوكلاء حتى بعد إزالة OpenCode.

## هل يعمل مع OpenCode v1؟

لا. يتطلب التثبيت والتحقق CLI بإصدار رئيسي 2. افحص الإصدار باستخدام `opencode --version` واتبع تعليمات OpenCode الرسمية للترقية بنفسك.

## هل أحتاج إلى إعداد نموذج أو مفتاح API لتثبيت الحزمة؟

لا يلزم ذلك لنسخ الوكلاء أو التحقق من بصمات ملفاتهم. لكن استخدام الوكلاء لمهام النموذج يتطلب مزوداً ونموذجاً صالحين مهيئين في OpenCode.

## أين تثبت الوكلاء؟

في `<project>/.opencode/agents/`. أسماء الوكلاء تتبع المسارات النسبية؛ مثلاً يصبح الوكيل الموجود في `backend/api.md` معرفاً مثل `backend/api`.

## هل يغير المثبّت الوكيل الافتراضي أو الصلاحيات؟

لا. لا يضبط `default_agent` ولا يوسع صلاحيات المشروع العامة. لكل ملف وكيل إعدادات وضع وأذونات V2 خاصة به.

## ما معنى `experimental.subagent_depth: 2`؟

يسمح بمستويين من التفويض المتداخل ضمن السلسلة المقصودة: المنسق العام ثم قائد فريق ثم اختصاصي. لا يفتح مستوى ثالثاً. يستخدم OpenCode V2 هذا المفتاح داخل `experimental`؛ لا تستخدم المفتاح الجذري القديم الذي يتجاهله V2.

## ماذا أفعل إذا كان ملف الإعداد JSONC؟

المثبت لا يعيد كتابة JSONC حتى لا يتلف التعليقات أو الفواصل. استخدم `install --no-depth-2` ثم ادمج المفتاح يدوياً في ملف الإعداد الفعّال. انظر [دليل التثبيت](INSTALLATION.md) و[دليل إعداد العمق](../INSTALL-OPENCODE-V2.md).

## ماذا يحدث إذا كان لدي ملف وكيل بالاسم نفسه؟

إذا كان مطابقاً تماماً لملف الحزمة، يتركه المثبت ولا يسجله كملف يملكه. إذا كان محتواه مختلفاً، يتوقف ويرفض الكتابة فوقه. لا يحذف الإلغاء الملفات التي لم يضفها المثبت.

## هل يحذف `uninstall` ملفاً عدلته؟

لا. يحتفظ بالملفات التي تغيرت بعد التثبيت، ويحتفظ بسجل الحالة عند الحاجة لمراجعة يدوية. كما يستعيد إعداد JSON سابقاً من نسخة احتياطية فقط عندما تكون بصمته مطابقة لما سجله المثبت.

## هل يحذف `uninstall` OpenCode أو إعداداته العامة أو الجلسات؟

لا. يدير ملفات الوكلاء وإضافة إعداد المشروع التي أنشأها أو عدلها فقط. لا يحذف CLI أو إعدادات المستخدم العامة أو الجلسات.

## لماذا يقول `verify` إن وكيلاً غير موجود؟

تأكد أن الأمر يعمل من جذر المشروع الصحيح، وأن OpenCode يتعرف عليه كمشروع، وأن ملفات الحزمة لم تعدل. يستدعي التحقق `opencode debug agents` ويقارن الملفات وبيانات التشغيل.

## هل يضمن اسم الوكيل توفر الأطر أو التكاملات المذكورة في تعليماته؟

لا. ملف الوكيل تعليمات وسياق فقط؛ لا يثبت تلقائياً مكتبات أو أدوات أو خدمات ولا يمنح أسراراً أو صلاحيات خارج إعداد OpenCode.

## هل يمكن تشغيل التثبيت من Windows؟

الطريقة الموثقة تستخدم Bash وأدوات Unix وPython 3.9+. استخدم WSL أو بيئة Bash متوافقة، وتأكد أن OpenCode v2 متاح فيها.

## كيف أبلغ عن مشكلة أو ثغرة؟

للمشكلة العامة استخدم قالب البلاغ في GitHub. للإبلاغ عن ثغرة أمنية، راجع [سياسة الأمان](../SECURITY.md) ولا تنشر تفاصيل الاستغلال في بلاغ عام.
